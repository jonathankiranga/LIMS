What This Module Does

The Cost Allocation module answers one question: "What does it cost us to run each test?"

It reads expenses already recorded in the General Ledger — salaries, rent, utilities, depreciation, equipment maintenance — and distributes them across lab tests based on configurable rules.

Important: This module does not create new GL entries. It only reads and allocates existing expenses for reporting purposes.

Before You Start

Make sure the following are already set up:

  • Tests are registered as active stock items
  • Labor amounts per test are set up in Test Labor Mapping
  • Fixed assets with depreciation rates are entered
  • Expenses are posted to the General Ledger (bills, journals, depreciation) and tagged to assets where applicable
  • Test results are recorded in the LIMS with status "completed", "approved", or "verified"

Setup (One-Time)

1. Map Tests to Labor Amounts

Open Test Labor Mapping. For each test, enter a flat Amount representing the labor cost per test. This replaces the previous role-rate × hours calculation — the amount is used directly as the labor basis for allocation.

2. Map Tests to Equipment

Open Test Equipment Mapping. For each test, select the equipment asset(s) it uses. Equipment cost is not calculated theoretically — instead, actual expenses posted to the General Ledger and tagged to each asset (via asset_id) are used as the allocation basis.

Note: Expenses must be posted to the GL with the correct asset tag. Use the asset selector in Enter Bills and enter depreciation via Fixed Asset Depreciation to ensure costs are attributed to the right asset.

3. Set Up Allocation Rules

Open Cost Allocation Rules. Each rule tells the system which GL account to read and how to spread the cost:

DriverHow It WorksBest For
Labor HoursSpread based on labor hours per testSalaries, utilities, rent, insurance
Equipment HoursSpread based on actual GL costs tagged to each assetDepreciation, calibration, repairs
Fixed Per TestDivide equally across all testsSoftware subscriptions, flat fees

Reading the Report

The Cost Accounting Report shows a spreadsheet with these columns:

ColumnWhat It Shows
TestTest name
TestsNumber of test instances completed in the period
MaterialReagent costs traced directly to the test
LaborAllocated salary and overtime costs
EquipmentAllocated depreciation and maintenance costs
OverheadAllocated utilities, rent, insurance, and other overhead
TotalSum of all cost components
Cost/TestTotal divided by number of tests = cost per individual test

Filtering: Use the From/To date fields to filter by date range, or select a previously run period from the dropdown. Click Export CSV to download.

Allocation Rules

Rules map GL expense accounts to allocation drivers. You can add, edit, or deactivate rules via the Rules page. A rule only produces results if the GL account has actual expenses in the period.

Report is emptyRun the allocation first before viewing the report
Test not in mapping dropdownEnsure the test is active and registered as a stock item
