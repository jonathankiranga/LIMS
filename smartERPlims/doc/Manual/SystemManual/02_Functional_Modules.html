Inventory Serial Number Tracking

Serial numbers are generated automatically when a Goods Received Note (GRN) is posted for a Stock Master item configured with requireserial = 1. They are not generated when a Purchase Order is created or approved.

  1. Open Inventory → Maintenance → New Stock and ensure serial tracking is enabled for the item (stockmaster.requireserial = 1).
  2. Create and process the Purchase Order as usual.
  3. Receive the goods through the Goods Received Note transaction.
  4. Post the GRN. During stock posting, the system creates one serialised StockRegister receipt row per whole loose unit received.
  5. Open Purchases → Reports → Last Serial Numbers (Goods Received) to review or print recently generated serial numbers.

Unit conversion: If the GRN line uses the full-unit UOM, the received quantity is multiplied by stockmaster.partperunit to obtain loose units. If it uses the loose-unit UOM, the entered quantity is used directly.

Serial format: [barcode or item code][two-digit year][four-digit yearly counter]. The item barcode is used when available; otherwise the item code is used. The counter is shared across serialised items within the year.

Example: Barcode ABC, year code 26, and counter 0001 produce ABC260001.

Important: Items without serial tracking enabled are received as normal stock quantities and do not receive individual serial numbers. The report only prints existing serial numbers; it does not create them.
